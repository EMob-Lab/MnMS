Usage:
  mnms-docker <settings>.json          Run a MnMS simulation configured through a JSON file
  mnms-docker <script>.py [args...]    Run a MnMS simulation defined by a custom Python script

All files used by the simulation (the JSON settings file or Python script,
and any file they reference) must be located in the current directory
or one of its subdirectories, and referenced by relative paths.

Paths written inside the JSON settings file or Python script must use '/'
as path separator, including on Windows.
